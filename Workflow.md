# Как работать над проектом

## Окружение

Для удобства работы над проектом используются инструменты из **Node.js** и **npm**. Все необходимые настройки произведены. Убедитесь, что на рабочем компьютере установлен актуальный LTS релиз Node.js**. Актуальная версия **Node.js** указана в файле `package.json` в поле `node`. Затем, в терминале, перейдите в директорию с проектом и _единожды_ запустите команду:

```bash
npm install
```

Команда запустит процесс установки зависимостей проекта из **npm**.

### Сценарии

В `package.json` предопределено несколько сценариев.

#### Скомпилировать проект

```bash
npm run compile
```

Создаст директорию `dist` и скомпилирует проект.

#### Удалить скомпилированный проект

```bash
npm run clean
```

Удаляет директорию `dist`. Используется перед компиляцией.

#### Собрать проект

```bash
npm run build
```

Выполняет сборку проекта: удаляет ранее скомпилированный проект и компилирует заново.

#### Проверить линтером

```bash
npm run lint
```

Запуск проверки проекта статическим анализатором кода **ESLint**.

Линтер проверяет файлы только внутри директории `src`.

**Обратите внимание**, при запуске данной команды, ошибки выводятся в терминал.

#### Запустить ts-модуль без компиляции

```bash
npm run ts -- <Путь к модулю с ts-кодом>
```

Пакет `ts-node` позволяет выполнить TS-код в Node.js без предварительной компиляции. Используется только на этапе разработки.

#### Запустить тестовый сервер с моковыми данными

```bash
npm run mock:server
```

Запускает `json-server` на порту `3123` с данными из `mocks/mock-server-data.json`. Заготовки для генерации предложений доступны по адресу `http://localhost:3123/api`. Используется командой CLI `--generate`.

#### Запустить CLI

```bash
npm run cli -- --<command> [--arguments]
```

Запускает CLI-приложение (`src/main.cli.ts`) для подготовки данных. Без аргументов выполняет команду `--help`. Поддерживаемые команды:

- `--help` — выводит список команд;
- `--version` — выводит версию приложения из `package.json`;
- `--generate <n> <path> <url>` — генерирует `n` тестовых предложений на основе данных с сервера `url` и сохраняет их в TSV-файл `path`;
- `--import <path> <db-uri> <salt>` — импортирует предложения из TSV-файла `path` в базу данных MongoDB по адресу `db-uri`, пароли пользователей хешируются с солью `salt`.

#### Запустить проект

```bash
npm start
```

В процессе запуска проекта будет выполнен процесс «Сборки проекта» и запуска результирующего кода.

#### Запустить проект в режиме разработки

```bash
npm run start:dev
```

Запускает REST-приложение (`src/main.rest.ts`) через `ts-node` без компиляции. Логи форматируются с помощью `pino-pretty`. Перед запуском создайте файл `.env` по образцу `.env.example`.

## Переменные окружения

Все переменные обязательны. Если какая-то переменная не задана, сервис выводит сообщение об ошибке и прекращает работу. Пример заполнения — в файле `.env.example`.

- `PORT=4000` — порт, на котором сервис принимает входящие подключения;
- `DB_HOST=127.0.0.1` — IP-адрес сервера базы данных MongoDB;
- `DB_PORT=27017` — порт сервера базы данных;
- `DB_USER=admin` — имя пользователя для подключения к базе данных;
- `DB_PASSWORD=test` — пароль для подключения к базе данных;
- `DB_NAME=six-cities` — название базы данных;
- `SALT=example-salt-change-me` — соль для хеширования паролей пользователей;
- `UPLOAD_DIRECTORY=upload` — директория для файлов, которые загружают клиенты (аватары). Раздаётся по адресу `/upload`;
- `STATIC_DIRECTORY=static` — директория со статическими файлами сервиса (аватар по умолчанию). Раздаётся по адресу `/static`;
- `JWT_SECRET=example-jwt-secret-change-me` — секрет для подписи JWT-токенов.

## Запуск проекта

1. Установите зависимости:

   ```bash
   npm install
   ```

2. Запустите MongoDB и `mongo-express` в Docker. Интерфейс `mongo-express` будет доступен по адресу `http://localhost:8081`:

   ```bash
   docker compose up -d
   ```

3. Создайте файл `.env` по образцу `.env.example` и при необходимости измените значения переменных (см. раздел «Переменные окружения»).

4. Наполните базу тестовыми данными (необязательно). Запустите сервер с моковыми данными, сгенерируйте файл с предложениями и импортируйте его в базу:

   ```bash
   npm run mock:server
   npm run cli -- --generate 100 ./mocks/generated.tsv http://localhost:3123/api
   npm run cli -- --import ./mocks/generated.tsv "mongodb://admin:test@127.0.0.1:27017/six-cities?authSource=admin" <SALT из .env>
   ```

5. Запустите сервис в режиме разработки или соберите и запустите его:

   ```bash
   npm run start:dev
   npm start
   ```

Сервис будет доступен по адресу `http://localhost:4000` (порт задаётся переменной `PORT`). Описание ресурсов — в спецификации `specification/specification.yml`.

## Структура проекта

### Директория `src`

Исходный код проекта: компоненты, модули и так далее. Структура директории `src` может быть произвольной.

### Файл `Readme.md`

Инструкции по работе с учебным репозиторием.

### Файл `Contributing.md`

Советы и инструкции по внесению изменений в учебный репозиторий.

### Остальное

Все остальные файлы в проекте являются служебными. Пожалуйста, не удаляйте и не изменяйте их самовольно. Только если того требует задание или наставник.
